# Description:
This project is built on Angular 21 and Spring Boot to provide the full range of CRUD operations
on a connected database while serving a visually appealing front end to users.
The idea of this project is to allow users to create surveys and later view and modify them as they'd like.
To achieve this, I used Angular to provide the front end and navigation between all the different pages. I also 
used Bootstrap CSS and JS to create responsive elements throughout the website. On the backend, I used Spring Boot
and Spring Data JPA to provide an interface and ORM for ease of access to the database. The database
I used was an RDS instance of MySQL, served on AWS. 

# Implementation:
### Backend
To implement the backend of the application, I created a Survey entity along with a JpaRepository to handle all the
CRUD operations that would be needed to manipulate the Survey records in the database. The utilize the CRUD operations,
I created a SurveyController to map URL and HTTP methods for creating, reading, updating, and deleting. To encourage
data integrity, I created public enums that map to some of the Survey fields that correspond to checkboxes or radio
buttons.
### Frontend
For the frontend, there were 4 major components used throughout the application. The first was the welcome page, which
exists simply to provide links to create and view submitted surveys. The next is the survey form page. This is where
the user will create new surveys. A GET HTTP method is implemented to actually save these surveys into the database. 
The survey list page simply lists all the created surveys using another GET call. The survey view page allows users to
view, update, and delete any specific survey. For visual styling, Bootstrap was used.
### Other Notes
All other aspects of the project code were either files generated by the Spring Boot and Angular frameworks, or npm
modules that were installed to support the application. Files created solely by me have comments as needed.
